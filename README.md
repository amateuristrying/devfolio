# Devfolio - Abhiroop

A sleek, minimal developer portfolio with GSAP animations, slot-machine transitions, and interactive text-decode effects.

## Features
- **Hero Landing**: Clean typography with Gotham/Inter styling and green accent floor.
- **Slot Machine Transition**: Smooth GSAP overlay transitioning to the "Know More" page.
- **Interactive Decode Effect**: Rapid digital cipher/text scramble effect on hover across left section titles, buttons, and social links.
- **Persistent Green Bottom**: Zero white gaps on overscroll or hard scrolling.
- **Cloudflare Pages Ready**: Out-of-the-box static deployment with custom headers.

## Deployment on Cloudflare Pages
1. Go to the [Cloudflare Dashboard](https://dash.cloudflare.com/) > **Workers & Pages** > **Create application** > **Pages** > **Connect to Git**.
2. Select repository: `amateuristrying/devfolio`.
3. In Build settings:
   - **Framework preset**: `None`
   - **Build command**: *(leave blank)*
   - **Build output directory**: `/`
4. Click **Save and Deploy**.
